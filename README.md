# Safira Dresses

Site de e-commerce de vestidos. O design foi feito no Figma e depois desenvolvido em HTML e CSS.

[Ver o design no Figma](https://www.figma.com/design/jKTMFV8NHcYfpXSmiKBujc/Safiradresses?node-id=0-1)

## O que tem no projeto

- Página inicial com banners, categorias e produtos mais vendidos
- Categorias de vestidos: curto, midi, longo, plus size e para casamento
- Acessórios: bolsas, cintos e joias
- Coleções e lançamentos (New In)
- Promoções: clube exclusivo e tempo limitado
- Páginas de conta (criar conta e entrar), sacola e sobre a marca
- Layout responsivo, com ajustes para telas de até 768 px e 480 px

## Tecnologias

- HTML
- CSS
- Figma (design e protótipo)

## Como abrir

Não precisa instalar nada. Baixe o repositório e abra o arquivo `index.html` no navegador.

```
git clone https://github.com/Lotth00/Safira_Dresses.git
```

## Estrutura

```
index.html      página inicial
style.css       estilos
Paginas/        demais páginas, separadas por assunto
IMG/            imagens do site
```

## Observação

Projeto feito para estudo, sem back-end: a sacola e as contas são apenas telas.
